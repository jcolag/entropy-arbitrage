August doesn't have many holidays for us to latch onto, so fair warning, this month's developer diaries will end up naming themselves for an assortment of sometimes-odd anniversaries.  Case in point, today marks the 248<sup>th</sup> anniversary of the premiere of Salieri's {% wiki Europa_riconosciuta|**Europa riconosciuta** %}, which itself marked the opening of {% wiki La_Scala|La Scala|en %}.

![La Scala in Milan](/blog/assets/la-scala.png "Having listened to a couple of passages from the opera, part of me wonders if its too-hip-for-the-room attitude might have inspired the fictional Don Juan Triumphant from The Phantom of the Opera...the novel, I mean; the musical has a much more open inspiration")

And with that, on to the week's projects.

## Scrawls

{% codeberg jcolag/scrawls %}

We now have a default configuration file to identify the [Code Mirror](https://codemirror.net/5/) version and (unused so far) the starting path.  The code should also look significantly cleaner.

Along the way, it hasn't gotten entirely wired up, yet, but you can see the start of tracking the open files and setting a flag for files with changes.

The application can also (finally?) save the open file, though it probably needs some work to make sure that a race condition doesn't wreck a file.

## Library Updates

I bumped a bunch of library versions on [Miniboost](https://github.com/jcolag/Miniboost).

## Next

Scrawls still has a long way to go, but I may also take some time to clear out the library updates for projects primarily over on Codeberg.

Also, it looks like the [Wikimedia Foundation has refused to recognize the union](https://wikiworkersunited.org/announcements/2026-07-28-us-nlrb-election/), so I'll probably carve out a couple of hours to go convert all current direct links to Wikipedia pages into my plugin.  They'll continue to point to Wikipedia for now, but if the union calls for action, then I'll have the capacity to change the URLs at once to a mirror, since I'd rather not cross the notional picket line.  Mind you, I need to *find* a decent mirror for this to work.
